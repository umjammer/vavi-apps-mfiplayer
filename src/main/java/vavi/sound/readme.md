# vavi.sound

### Packages

the sound sources are pure chip emulation and know nothing of the file format played on them,
what a song brings besides the midi is told to them by the synthesizer of its format

| package                                                                                                                                                                                                                                                                                                  | what                                                                           |
|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------|

| [`vavi.sound.rohm`](src/main/java/vavi/sound/rohm/readme.md)                                                                                                                                                                                                                                             | the rohm sound source (faith Type 2), a port of `rt_synth_2.dll`               |
| [`vavi.sound.ucs`](src/main/java/vavi/sound/ucs/readme.md)                                                                                                                                                                                                                                               | the fuetrek sound source (faith Type 4), the rom of `rt_synth_4.dll`           |
| `vavi.sound.faith`                                                                                                                                                                                                                                                                                       | where the faith authoring tool's dlls are                                      |
| [`vavi.sound.mfi.ma7`](src/main/java/vavi/sound/mfi/ma7/readme.md), [`.rohm`](src/main/java/vavi/sound/mfi/rohm/readme.md), [`.ucs`](src/main/java/vavi/sound/mfi/ucs/readme.md)                                                                                                                         | the mfi synthesizers on them: the mfi values of vavi, the UCS waves, the adpcm |
